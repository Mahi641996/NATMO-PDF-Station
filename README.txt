# NATMO PDF Station

An offline, desktop-only PDF utility developed for internal use at  
**National Atlas & Thematic Mapping Organisation (NATMO)**  
Department of Science & Technology, Government of India.

## Features
- Merge PDF files
- Split PDF (multiple page ranges)
- Delete selected pages
- Rotate / Flip PDF pages
- Convert JPG / PNG to PDF

## How to Use
1. Download the ZIP file from GitHub
2. Extract the folder
3. Open `index.html` in Google Chrome or Microsoft Edge
4. Select required operation and follow on-screen instructions

## Requirements
- Google Chrome or Microsoft Edge
- No internet connection required after download
